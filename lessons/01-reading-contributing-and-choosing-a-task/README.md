# Lecture 01: Reading CONTRIBUTING.md & Choosing a Task

**Goal:** Master the core process of open source contribution — from understanding the history and culture, to reading project guidelines, finding beginner-friendly tasks, and opening your first Pull Request.

## How to Follow This Lecture

1. Read the sections sequentially from Section 01 to Section 07.
2. Open referenced repository files and real-world projects in a separate tab as you read.
3. Complete Section 07 on your machine to practice the Git and GitHub contribution lifecycle.
