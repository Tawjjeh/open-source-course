# Contributing to Open Source Course

Thank you for your interest in improving this course. Contributions help keep the materials accurate, clear, and accessible for beginners.

---

## Ways to Contribute

You can contribute in three ways:

1. **Report an Error:** If you find a typo, broken link, or factual inaccuracy, please open an issue using the "Report an Error" template.
2. **Suggest an Improvement:** If you have an idea to clarify an explanation or enhance a diagram, submit an issue using the "Suggest an Improvement" template.
3. **Submit a Pull Request:** If you can fix an existing typo or correct an identified error yourself, submit a concise Pull Request.

---

## Contribution Guidelines

To keep the repository organized and easy to maintain, please follow these rules:

- **Open or reference an issue first:** For anything beyond fixing an obvious typo, please discuss the change in an issue before opening a Pull Request.
- **English only:** All course materials, commit messages, and issue discussions must be written in English.
- **No emojis or decorative icons:** Keep the materials clean and distraction-free.
- **Verify facts and links:** Never guess dates, names, or URLs. Always verify against official documentation or add a `<!-- VERIFY: ... -->` comment if uncertain.
- **Focused changes:** Keep Pull Requests small and focused on a single topic or fix. Avoid reformatting unrelated files.

---

## Submitting a Pull Request

1. Fork the repository and create a new branch from `main`:
   ```bash
   git checkout -b fix/your-change-description
   ```
2. Make your edits cleanly and verify Markdown formatting.
3. Commit your changes with a clear message:
   ```bash
   git commit -m "Fix typo in lesson 01 history"
   ```
4. Push your branch to your fork:
   ```bash
   git push origin fix/your-change-description
   ```
5. Open a Pull Request against the `main` branch with a short explanation of what you changed.

---

All contributors are expected to uphold our [Code of Conduct](CODE_OF_CONDUCT.md). Please treat fellow contributors and learners with respect.
