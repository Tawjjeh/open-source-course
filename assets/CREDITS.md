## Guidelines for Adding New Assets

Before adding any image or media asset to this repository:
1. Verify the asset is openly licensed (e.g. Public Domain, CC0, CC BY, or CC BY-SA) or created directly by the course authors.
2. Record the exact local file path under `File`.
3. Credit the original `Author`.
4. Provide the canonical, permanent `Source URL` (such as a direct Wikimedia Commons file page).
5. State the exact `License` under which the asset was acquired.
